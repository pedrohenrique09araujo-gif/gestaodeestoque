# Delooe - Gestão de Estoque
Abra a pasta Delooe no IntelliJ IDEA como projeto Maven. Configure JDK 17 ou superior, aguarde as dependências e execute Main.java. O banco estoque.db é criado automaticamente. Protótipo local com Swing e SQLite, sem autenticação. O histórico registra entradas e saídas manuais, não cadastros ou exclusões.
